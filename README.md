# 咲耶フットボール（SAKUYA FOOTBALL）

CNP チームを操って忍者チームと戦う、80年代アーケード風の見下ろし型サッカーゲームです（縦長のフィールドを上へ攻める）。
咲耶シリーズの共通フレームワーク [sakuya-kit](https://github.com/naonao1971/sakuya-kit)（0.8.0）を使っています。

## 遊び方
- 3分間の試合で、相手より多く点を取れば勝ち（クリア）
- スコア: ボールを奪う +50、パスが味方に届く +30、枠に飛んだシュート +100（キーパーに取られても）、ドリブルで相手を抜く +50、ゴール +1000（その CNP の初ゴールは さらに +300）、勝ち +3000＋点差×500。点が入るたびに、その場所に数字が出る
- ダッシュは押している間だけ速くなる。走りすぎるとスタミナが切れて、その選手はしばらくダッシュできない（左のパネルのバー）
- ボールを持っているとき: A でシュート（押し続けると強いシュート。ゴールの近くでボールを持つと、ゴールの上で金の▼が左右に動く。A を押した瞬間の▼の位置へ飛ぶ）、B でパス（長押ししてから離すと浮き玉）、A＋B でロングシュート
  - パス先の味方の足もとに水色の点線の輪が出る（浮き玉になる長さまで押すと、明るい二重の輪と ×）。輪の出ている味方に蹴る。パス先がいなければ、蹴り出す向きに矢印が出る
- ボールを持っていないとき: A でスライディング、B で選手の切り替え
  - スティックを離すと、少ししてボールに近い選手に自動で切り替わる（スティックを倒して走っている間は切り替わらない）。切り替わった選手は足もとが光る

## スルーパス
- ボールを持ってダッシュしながら、またはダッシュをやめてすぐ（約0.7秒以内）に B を押すと、向いた方向の先の空いたところへパス。行き先に水色の ×、走り込む味方に水色の輪が出て、その味方が全力で走り込む（操作もその味方に移る）
- B を長押しすると浮き玉のスルーパス（「LOB THROUGH」）。相手の頭を越えて、もっと遠く（最大360px）へ出せ、落ちたところで止まる
- 安全な行き先がないときも、一番届きそうな味方へ出す（前に味方がいないときだけ、いつものパス）

## 体でキープ
- ボールを持っているとき、近くの忍者に背中を向ける（スティックで忍者と反対の方を向く）と、体でボールを守って取られにくくなる。足もとに金の弧と「KEEP」が出る。後ろからのスライディングも空振りしやすい

## キーパー
- CNP のキーパーがボールを持つと、操作がキーパーに移る。スティックで向きを変え、B で向いている方の味方の足もとへパス（長押しで浮き玉）、A で前へ大きく蹴る。何もしなければ約4秒で自動で蹴る

## セットプレーと風
- コーナーキック: 守る側が最後に触ってゴールラインを割るとコーナーキック（攻める側が触っていればゴールキック）。蹴る選手はコーナーから動けず、スティックで向きを変える。B で向いている方の味方へ（長押しで浮き玉）、A でゴール前へクロス。キーパーが弾いたシュートや、体でブロックしたボールが割ることが多い
- スローイン: 頭の上にボールを持ち、その場から動けない。B を短く押すと向いている方の味方へ、長押しするとロングスロー（押すほど遠く・最大 260px。落ちる場所に × と「LONG THROW」）。A は一番遠くへのロングスロー
- 風: 試合ごとに向きと強さ（0〜5m）が決まる。四すみのコーナーフラッグが風の向きになびき、右のパネルの「WIND」に向きと強さが出る。浮いているボールほど少し流される（浮き玉・クロス・ロングスローで効く）
- キーパーのセーブ: 忍者チームのシュートがゴールへ向かってくると、操作が CNP のキーパーに移る（「B:CATCH A:PUNCH」と出る）。スティックで動き、B でキャッチ、A でパンチング（ボールへ飛びつく）。ボタンなしで当たると取りにくい（いつもの確率×0.6）。数字は GK_SAVE で調整
- ゴール前の浮き球は、近くに守る選手がいると競り合いになり、3回に2回くらいは守る側が跳ね返す。キーパーはゴール前に落ちてくるクロスに飛び出す

## 練習モード
- ⚙ の「練習モード（キーパーだけ）」を ON にしてスタートすると、相手はキーパーだけ。時間切れもランキング登録もないので、パス・シュート・ヘディングをゆっくり練習できる
- OFF にすると普通の試合に戻る（プレー中に切り替えたら、設定を閉じたところで始め直す）。設定はこの端末に覚える

## 操作
| | PC | スマホ（横持ち） |
|---|---|---|
| 移動 | 矢印 / WASD | 画面の左半分を押したまま倒す |
| A | X | 右下の A |
| B | Z | 右下の B |
| ダッシュ（押している間） | C | 画面の右側の空いたところ（A・B 以外） |
| スルーパス | C を押したまま（離して0.7秒以内でも）Z。長押しで浮き玉 | 右側を押したまま（離して0.7秒以内でも）B。長押しで浮き玉 |
| 一時停止 / 音 | P / M | ⚙ |
