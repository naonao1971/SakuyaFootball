# 咲耶フットボール（SAKUYA FOOTBALL）

CNP チームを操って忍者チームと戦う、80年代アーケード風の見下ろし型サッカーゲームです（縦長のフィールドを上へ攻める）。
咲耶シリーズの共通フレームワーク [sakuya-kit](https://github.com/naonao1971/sakuya-kit)（0.8.0）を使っています。

## 遊び方
- 2分間の試合で、相手より多く点を取れば勝ち（クリア）
- ボールを持っているとき: A でシュート（押し続けると強いシュート）、B でパス
- ボールを持っていないとき: A でスライディング、B で選手の切り替え

## 操作
| | PC | スマホ（横持ち） |
|---|---|---|
| 移動 | 矢印 / WASD | 画面の左半分を押したまま倒す |
| A | X | 右下の A |
| B | Z | 右下の B |
| 一時停止 / 音 | P / M | ⚙ |
