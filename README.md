# 咲耶フットボール（SAKUYA FOOTBALL）

CNP チームを操って忍者チームと戦う、80年代アーケード風の見下ろし型サッカーゲームです（縦長のフィールドを上へ攻める）。
咲耶シリーズの共通フレームワーク [sakuya-kit](https://github.com/naonao1971/sakuya-kit)（0.8.0）を使っています。

## 遊び方
- 2分間の試合で、相手より多く点を取れば勝ち（クリア）
- ダッシュは押している間だけ速くなる。走りすぎるとスタミナが切れて、その選手はしばらくダッシュできない（左のパネルのバー）
- ボールを持っているとき: A でシュート（押し続けると強いシュート）、B でパス（長押ししてから離すと浮き玉）、A＋B でロングシュート
  - パス先の味方の足もとに水色の点線の輪が出る（浮き玉になる長さまで押すと、明るい二重の輪と ×）。輪の出ている味方に蹴る。パス先がいなければ、蹴り出す向きに矢印が出る
- ボールを持っていないとき: A でスライディング、B で選手の切り替え
  - スティックを離すと、少ししてボールに近い選手に自動で切り替わる（スティックを倒して走っている間は切り替わらない）。切り替わった選手は足もとが光る

## 操作
| | PC | スマホ（横持ち） |
|---|---|---|
| 移動 | 矢印 / WASD | 画面の左半分を押したまま倒す |
| A | X | 右下の A |
| B | Z | 右下の B |
| ダッシュ（押している間） | C | 画面の右側の空いたところ（A・B 以外） |
| 一時停止 / 音 | P / M | ⚙ |
