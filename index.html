遊び方
  • CNP チーム（青）を操って、忍者チーム（赤）と2分間の試合。勝てばクリア
  • ボールを持っているとき: A でシュート（押し続けると強いシュート。ゴールの近くでボールを持つと、ゴールの上で金の▼が左右に動く。A を押した瞬間の▼の位置へ飛ぶ）、B でパス（向いている方の味方の足元へ。パス先の味方の足もとに水色の輪が出る。長押ししてから離すと浮き玉）、A と B を同時に押すとロングシュート（どこからでもゴールへ。左右を入れるとすみを狙う）
  • 点数: ボールを奪う +50、パスが味方に届く +30、枠に飛んだシュート +100（キーパーに取られても）、ドリブルで相手を抜く +50、ゴール +1000（その CNP の初ゴールは さらに +300）。点が入るたびに、その場所に数字が出る
  • 浮き球: ボールが浮いて近くにあるときに A を押すと、高ければヘディング、低ければボレーで直接蹴る（ゴールの近くで前を向いていればシュート）
  • ボールを持っていないとき: A でスライディング、B で選手の切り替え（スティックを離すと、ボールに近い選手に自動でも切り替わる。走っている間は切り替わらない。切り替わった選手の足もとが光る）
  • スマホ: 左半分を押したまま倒して移動 ・ 右下の A / B ・ ⚙ で音・全画面の設定
  • ダッシュ: スマホは画面の右側の空いたところ（A・B 以外）を押している間、PC は C キーを押している間、操作中の選手が速くなる。走りすぎるとスタミナが切れて、その選手はしばらくダッシュできない（左のパネルのバー）
  • スルーパス: ボールを持ってダッシュしながら、またはダッシュをやめてすぐ（約0.7秒以内）に B を押すと、向いた方向の先の空いたところへパス。行き先に水色の ×、走り込む味方に水色の輪が出て、その味方が全力で走り込む。B を長押しすると浮き玉のスルーパス（「LOB THROUGH」。相手の頭を越えて、もっと遠くへ）
  • 体でキープ: ボールを持っているとき、近くの忍者に背中を向ける（スティックで忍者と反対の方を向く）と、体でボールを守って取られにくくなる。足もとに金の弧と「KEEP」が出る。後ろからのスライディングも空振りしやすい
  • キーパー: CNP のキーパーがボールを持つと、操作がキーパーに移る。スティックで向きを変え、B で向いている方の味方の足もとへパス（長押しで浮き玉）、A で前へ大きく蹴る。何もしなければ約4秒で自動で蹴る
  • 練習モード: ⚙ の「練習モード（キーパーだけ）」を ON にしてスタート。相手はキーパーだけで、時間切れもランキング登録もない。OFF にすると普通の試合に戻る
  • PC: 矢印 / WASD で移動 ・ X が A ・ Z が B ・ C を押している間ダッシュ ・ P 一時停止 ・ M 音
  • 姉妹作: 咲耶スクランブル / 咲耶Nounラリー / 咲耶ジャンプバグ
