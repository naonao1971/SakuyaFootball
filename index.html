遊び方
  • CNP チーム（青）を操って、忍者チーム（赤）と2分間の試合。勝てばクリア
  • ボールを持っているとき: A でシュート（押し続けると強いシュート。ゴールの近くで前を向くと、ゴールの上に金の▼が出て、そこへ飛ぶ。上と左右をいっしょに入れると▼がすみへ動く）、B でパス（向いている方の味方の足元へ。パス先の味方の足もとに水色の輪が出る。長押ししてから離すと浮き玉）、A と B を同時に押すとロングシュート（どこからでもゴールへ。左右を入れるとすみを狙う）
  • 浮き球: ボールが浮いて近くにあるときに A を押すと、高ければヘディング、低ければボレーで直接蹴る（ゴールの近くで前を向いていればシュート）
  • ボールを持っていないとき: A でスライディング、B で選手の切り替え（スティックを離すと、ボールに近い選手に自動でも切り替わる。走っている間は切り替わらない。切り替わった選手の足もとが光る）
  • スマホ: 左半分を押したまま倒して移動 ・ 右下の A / B ・ ⚙ で音・全画面の設定
  • ダッシュ: スマホは画面の右側の空いたところ（A・B 以外）を押している間、PC は C キーを押している間、操作中の選手が速くなる。走りすぎるとスタミナが切れて、その選手はしばらくダッシュできない（左のパネルのバー）
  • PC: 矢印 / WASD で移動 ・ X が A ・ Z が B ・ C を押している間ダッシュ ・ P 一時停止 ・ M 音
  • 姉妹作: 咲耶スクランブル / 咲耶Nounラリー / 咲耶ジャンプバグ
